## Implemented slices

**M1 — MPP and encoderd.** Full-resolution KA2 input uses the DMA-BUF import path without a copy or fallback. MPP tracks submitted inputs, published packets, and pending frame identities. The encoder recovery policy uses published-packet progress, per-output watchdogs, isolated retry/backoff, and output-only quarantine after the shared drain deadline. The corrected `encoderd.cc` includes the production-used `retry_output_policy` helper: retry timing is per-output, backoff resets only after valid packet progress, and recovery reopens assign the current segment before accepting new frames. Healthy qRoad continues through the planned segment reopen without sibling retry/recovery.

**M2 — loggerd.** KA2 deterministic rotation uses the timer-based readiness deadline and a shared commit timestamp for rotation reporting and audio finalization. Reports retain their fixed schema and observed-drop counters. The bounded qRoad audio queue preserves timestamp order and rejects newest data before allocating beyond its cap.

**M1/M4 — PC FFmpeg legacy path.** The non-RK3588/HardwarePC test build links the FFmpeg encoder. For qRoad, it applies the configured bitrate, GOP size, and B-frame count, then selects FFmpeg `ultrafast` and `zerolatency`. PTS now advances in monotonic frame ticks and resets on encoder open, replacing the incorrect fixed 50 ms calculation. This lets PC qRoad produce timely packets through segment changes while the legacy software configuration keeps its separate rotation behavior.

**M0/M3 — test fixtures and lifecycle coverage.** Test-builder added isolated DMA-heap and memfd VisionIPC fixtures, MPP recovery and drain assertions, loggerd report/audio tests, and the non-RK software-branch lifecycle. The AC-6 drain test also checks a test-only all-output reopen counter compiled under `LOGGERD_TEST_BUILD` and gated by `LOGGERD_TEST=1`: counting starts after the first valid frame, and each road, driver, and wide-road thread emits exactly one zero-count record at shutdown. Startup construction is outside the counted interval. The test-only targets are isolated in `SConscript`; production binaries omit fault hooks and this counter.
